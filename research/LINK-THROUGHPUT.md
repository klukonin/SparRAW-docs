# Пропускная способность 60-ГГц линка и цена снятия окна AW

Нагрузочные измерения линка AP–STA на стенде (4.1.0.1000). Узлы вынесены из моста в отдельную
подсеть, так что трафик между ними идёт только через 60 ГГц. Метка: **[железо]**.

## 1. Скорость по `iw` и по трафику

`iw` в простое показывает скорость простоя (27,5 / 385 Мбит/с при −72 дБм); под нагрузкой — сразу
2310 Мбит/с. Фактическая пропускная способность TCP — **около 985 Мбит/с**. Состояние линка
оценивается трафиком, а не показаниями `iw`.

## 2. Устойчивость под нагрузкой

Единичный отказ станции при полноскоростном `iperf3` ступенчатой нагрузкой не воспроизводится:

| нагрузка | потери | узлы |
|---|---|---|
| UDP 2, 5, 10, 15, 20, 25 Мбит/с | 0 % | живы |
| UDP 40, 60 Мбит/с | 0 % | живы |
| TCP 10, 30 Мбит/с | — | живы |
| TCP без ограничения, 4 и 12 с | — | живы, 741…916 Мбит/с |

Джиттер UDP падает с 0,164 мс (2 Мбит/с) до 0,005 мс (25 Мбит/с). Отказ случился на стенде с
накопленным состоянием (в т. ч. зависшее ядро CPU 3 на узле AP) — вероятнее накопительная
неустойчивость, чем зависимость от нагрузки.

## 3. Снятие окна AW не стоит пропускной способности

A/B по 6 прогонов TCP по 10 с (Мбит/с):

| | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| AW снято (`bi_mode = 2`) | 732 | 736 | 980 | 983 | 985 | 963 |
| AW работает (`bi_mode = 1`) | 839 | 989 | 985 | 984 | 985 | 977 |

Просадка первых прогонов есть в обоих состояниях — это переходный процесс после записи
`bi_mode`, а не цена рычага. Установившиеся значения совпадают в пределах разброса: 963…985
против 977…989. Со снятым AW станция остаётся ассоциированной, keep-alive проходят без отказов.

Разрешающая способность метода недостаточна для прямого эффекта: снятие AW возвращает 1005 мкс
из 102 400, т. е. 0,98 % эфирного времени (≈ +10 Мбит/с при 985 Мбит/с), а разброс прогонов
±1,3 %. Возврат времени доказывается границами окон по меткам TSF: AW 1009 → 5 мкс, DTI +1005 мкс
([docs/BEACONING.md §9.4](https://github.com/klukonin/SparRAW-firmware/blob/main/docs/BEACONING.md)).

Рабочая пара PBSS на том же стенде — [PBSS-ON-HW.md](PBSS-ON-HW.md).
