# Пакеты RouterOS (npk): распаковка и шифрование fw/brd wil6210

Формат пакета, схема шифрования прошивки и board-файлов wil6210 и способ их расшифровки.
Метки: **[код]** — реверс `nova/bin/wireless`, **[данные]** — проверено на корпусе пакетов.

## 1. Пакет npk **[данные]**

* NPK = заголовок 4 КБ (magic `1e f1 d0 ba`) + xz-SquashFS 4.0 со смещения 0x1000.
* Содержимое, например `wireless-6.43.13-arm.npk`: `lib/firmware/wil6210.fw` (561252 Б,
  зашифрован), несколько `wil6210-*.brd` (зашифрованы), `wil6210.ko` (драйвер) и
  `nova/bin/wireless` (854 КБ, ARM) — загрузчик и дешифратор.
* Распаковщик — `SparRAW-tools/re/mikrotik_npk.py`.

## 2. Загрузчик fw/brd в `wireless` **[код]**

* Бинарник слинкован с OpenSSL (libcrypto/libssl): `AES_set_decrypt_key`, `AES_decrypt`,
  `AES_cbc_encrypt`.
* AES-128-CBC-дешифратор `FUN_000127c0` (ключ 128 бит в `obj+0x284`, IV — первые 16 байт
  контейнера, PKCS#7, SHA-256) относится к лицензии/конфигурации: у вызывающих — `memcmp` 16 байт
  и логирование; путь загрузки fw до него не доходит.
* Загрузчик fw/brd — `FUN_000a540c`: строит пути (`/pckg/wireless/lib/firmware/`, `wil6210.fw`,
  `wil6210-<board>.brd`), читает `nv::readFile`, разбирает как `nv::message` (`FUN_000a52d8` —
  десериализатор пар u32) и хэширует (`Hash::update`/`digest`).
* Деривация ключа (key stretching): `seed = string(param_1 + 0x8c)`; 1024 итерации
  `string::append` → `HashImpl::update` → `Hash::digest`; результат — 32 байта (SHA-256, алгоритм
  выбирается `DAT_000a6368`): `key32 = Hash^1024(seed)`.
* Тело board-файла после расшифровки — `nv::message` с board-структурой `0xBDF0BDF0`
  (формат multi-array wil6436), которую код дополнительно патчит (расширение секторов, маркер
  `0xC00C900D` по `DAT_a6374`).

## 3. Схема шифрования **[данные]**

```
plaintext = ciphertext XOR keystream
```

* Keystream высокоэнтропийный, без периода (256 значений равномерно). Извлечённые потоки в
  `keystreams/`: `58cfa159` и `f0e9cbc5` — 561252 Б, `967e9839` — 561160 Б, `6953384a` — 6668 Б
  (эпоха с открытой прошивкой, поток нужен только для board-файлов).
* Один keystream в пределах версии RouterOS расшифровывает и fw, и все board-файлы этой версии
  (keystream для `wap60g-60deg` и `cube` совпадают полностью).
* Keystream разный для разных «криптоэпох» (§4): keystream beta-версии (`58cfa159`…) не
  расшифровывает 6.43.13 (`f0e9cbc5`…). Разворот `key32` в поток — не простая цепочка хэшей;
  вероятно, RC4 или AES-CTR.

Форматы открытого текста:

| файл | начало | смысл |
|---|---|---|
| board | `02 00 00 00 <u32 len> 00 78 91 00 f0 bd f0 bd` | `nv::message` (tag 2, например len 0x0db4) + board `BDF0BDF0` |
| board (часть версий) | `06 00 00 00 34 00 00 00 30 31 32 36` | сырой контейнер wil6210 `0126` |
| firmware | `06 00 00 00 34 00 00 00 30 31 32 36` | контейнер wil6210 `0126` |

CRC в контейнерах RouterOS сломан намеренно (прошивку правят, CRC не пересчитывают).

## 4. Карта keystream по версиям **[данные]**

| RouterOS | fw | keystream board |
|---|---|---|
| 6.41.x, 6.42.1 | открытый | открытый (шифрования нет) |
| 6.43.12 | зашифрован | `967e9839` |
| 6.43.13, 6.44.5 | зашифрован | `f0e9cbc5` |
| 6.45.3 | зашифрован | `58cfa159` |
| 6.46.x, 6.47beta | открытый | `58cfa159` |
| 6.48.6, 6.49beta | открытый | `6953384a` |

Расшифровка по всем 12 версиям — без отказов. Keystream-ов четыре, они переиспользуются между
версиями. Бутстрап без реверса генератора:

* чиповая прошивка «6.2.0.1000» одинакова в разных RouterOS — известный открытый текст для
  извлечения keystream версии;
* открытый текст board-файла одной модели платы общий между эпохами (6.43.12 sa-omni == 6.48
  sa-omni) — keystream новой эпохи извлекается из известного board-файла без fw.

Ключ вида `xor_key`, полученный как `xored ⊕ plain` для конкретной прошивки 6.2, на другие
версии не переносится и даёт результат с битым CRC.

## 5. Инструменты

* `SparRAW-tools/re/mikrotik_decrypt.py --auto FILE…` — определение keystream и расшифровка;
  `--keystream KS in -o out` — расшифровка известным потоком; `--recover cipher plain -o ks` —
  извлечение потока из пары.
* `SparRAW-tools/re/keystreams/` — библиотека извлечённых keystream-ов.

## Не установлено

* Содержимое `seed` (`card+0x8c`): версия, имя платы или зашитая строка.
* Алгоритм разворота `key32` в keystream.
