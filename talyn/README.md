# Talyn (QCA6436, 802.11ay)

Чип Qualcomm **Talyn** (базовый кристалл QCA6436 / QCA6426, радиочастотный модуль TLNA2 / Marlon-R-v2, стандарт 802.11ay EDMG)
построен на той же процессорной микроархитектуре, что и **Sparrow** (QCA6310/6320/6335, 802.11ad):
оба ядра (fw и ucode) выполнены на 32-битном RISC-ядре ARC600 (ARCompact), управляются общим хостовым драйвером `wil6210`
и разделяют базовый регистровый массив RGF. В связи с этим исследования Talyn ведутся в рамках проекта SparRAW.

Основная исследованная версия: **Talyn 7.5.3.115** (MikroTik wireless 6.48.6 … 7.24.4), а также образы Terragraph **TG 10.11.0.92**.

---

## 1. Сравнительная архитектурная таблица: Sparrow vs Talyn

| Подсистема | Sparrow (QCA6310 / QCA6320 / QCA6335) | Talyn (QCA6436 / QCA6426) |
|---|---|---|
| **Стандарт радио** | 802.11ad (DMG, 60 ГГц) | 802.11ay (EDMG, 60 ГГц) |
| **Ширина канала** | Только CB1 (2,16 ГГц), каналы 1..4 (до 6) | CB1 (2,16 ГГц, кан. 1..6) и **CB2 (4,32 ГГц bonded, кан. 9..12)** |
| **Модуляция** | SC (MCS 1..12), OFDM (MCS 13..24) | SC (MCS 1..12), **EDMG SC (MCS 1..21)**, EDMG OFDM, NUC (Non-Uniform Constellation) |
| **Пространственные потоки** | SISO (1 TX, 1 RX тракт) | До 2x2 MIMO (spatial multiplexing), 2 TX / 2 RX потока |
| **Вычислительные ядра** | 2 ядра **ARC600** (fw @0x0, uc @0x0) | 2 ядра **ARC600** (fw @0x0 + @0xa0000, uc @0x0) |
| **Тактовая частота MAC** | 165 МГц (базовый такт 6,06 нс) | 165 МГц (совместимость) / 264 МГц / 330 МГц (EDMG/CB2) |
| **РЧ-тракт** | Marlon RFC / Sparrow-R (open-loop усиление) | **TLNA2 / Marlon-R-v2** (closed-loop TPC с TSSI-датчиками) |
| **Калибровка мощности (TPC)** | Статическая таблица (board file строка 7, 0x8840f8) | **Аппаратная замкнутая TPC** по MCS и температуре (WMI 0xa20) |
| **Хостовый интерфейс** | PCIe Gen2 x1, кольца Legacy vring (0x881xxx) | PCIe Gen2 x1/x2, **eDMA** (multi-queue дескрипторы, SCM) |
| **Планирование MAC** | DTI / ESE SP allocations (аппаратные слоты 0x5a) | Аппаратный движок **Terragraph TDD-TDMA** (синхр. слотов 0x5a) |
| **Точность меток времени** | 6,06 нс (ToA/ToD на 165 МГц, 0x88c110..1c) | 6,06 нс ToA/ToD + **аппаратный захват GPS PPS** (0x88c754/64) |
| **Multi-BSS / Multi-VIF** | 1 VIF (Single BSS в штатных fw 4.1/6.2) | **Multi-Network Engine** (аппаратный регистр `0x88613c`, 4 BSSID) |
| **Радиолокация (Sensing)** | Отсутствует | Аппаратный блок **радара FMCW/pulse** (`phy_radar_*`, sensing_mgr) |

## 2. Процессорные ядра и организация памяти

Оба процессора (fw — верхнеуровневое управление протоколом и LMAC; ucode — нижний уровень MAC, тайминги IFS, SIFS, beamforming)
выполнены на ядре **ARCompact / ARC600** (`mul64`, аппаратный умножитель 32x32->64, короткие 16-битные и длинные 32-битные инструкции).
Таблица векторов прерываний оформлена переходами `j limm`, выход из обработчиков выполняется через `j.f [ilink]`.
Инструкции ARC700 (`rtie`, `mpy`) в коде отсутствуют.

### Карта отображения сегментов (AHB $\to$ Link)

```
        SPARROW                               TALYN 7.5
0x900000 ┌──────────────────┐           0x900000 ┌──────────────────┐
         │ fw_code (0x0)    │                    │ fw_code (0x0)    │
0x920000 ├──────────────────┤           0x9a0000 ├──────────────────┤
         │ uc_code (0x0)    │                    │ fw_code2(0xa0000)│
0xa00000 ├──────────────────┤           0xa00000 ├──────────────────┤
         │ fw_data (0x80000)│                    │ fw_data (0x80000)│
0xa38000 ├──────────────────┤           0xa38000 ├──────────────────┤
         │ uc_code (0x0)    │                    │ uc_code (0x0)    │
0xa78000 ├──────────────────┤           0xa78000 ├──────────────────┤
         │ uc_data (0x80000)│                    │ uc_data (0x80000)│
         └──────────────────┘                    └──────────────────┘
```

- В Talyn 7.5 размер кода fw превысил 640 КБ, поэтому добавлен вторичный сегмент `fw_code2` по адресу AHB `0x9a0000`,
  линкуемый в адресное пространство ядра по смещению `0xa0000`.
- Область периферии RGF отображается в диапазоне `0x880000 … 0x8bffff`.

### Конвейер и статистика реверса Talyn 7.5.3.115
1. **Сегментация**: разбор образов на сегменты по AHB-адресам (`fw_code` 0x900000 $\to$ 0x0, `fw_code2` 0x9a0000 $\to$ 0xa0000, `fw_data` 0xa00000 $\to$ 0x800000, `uc_code` 0xa38000 $\to$ 0x0, `uc_data` 0xa78000 $\to$ 0x800000).
2. **Дизассемблирование**: Ghidra headless (языковой модуль ARCompact:LE:32:default) с окном периферии RGF `0x880000 … 0x8bffff`.
3. **Восстановление символов**: связывание строк системного журнала (`seed/`, `names/fwlog_names.py`, ссылки `limm 0x01000000|offset` в записях 0x65 fw / 0x64 uc).
4. **Регистровая трассировка**: сбор карты обращений (`regmap.py`, база mov/add + смещение ld/st).

| Ядро | Функций | Инструкций | Именованных из журнала | Регистров RGF (обращений) |
|---|---|---|---|---|
| **fw** | 3879 | 142 968 | 1598 | 898 (2922) |
| **uc** | 1078 | 65 146 | 299 | 275 (936) |

**Модули прошивки**: fw содержит 166 исходных файлов, uc — 86.
Ключевые модули Talyn, отсутствующие в Sparrow: `edmg_mgr` (uc), `channels_switch_sm` / `rm_ch_switch_sm`, `sensing_manager` / `sensing_mgr` (радар FMCW), `tof_mgr` / `hw_flows_phy_tof` (FTM), `rate_search`, `linear_power`, `thermal_throttling`, `multi_network_mgr`, `wbe_driver`, `hw_drivers_tlna2_rfc`.

## 3. Смена канала и бондинг CB1 / CB2 (Talyn 7.5 fw)


Управление радиоканалом сосредоточено в модуле `hw_modes_analog_manager.c`:
- **`hwm_ANALOG_CHANNEL_SWITCH`** @0x31e10:
  1. Остановка приемо-передающего тракта (TX/RX path silence).
  2. Перестройка частоты синтезатора РЧ-модуля.
  3. Вызов `file_hw_drivers_phy_11(ch)` — установка номера канала.
  4. Вызов `file_hw_drivers_phy_20(1, cb2)` — конфигурация полосы (флаг `cb2 = 1` при `5 < ch_enum < 10`).
  5. Ожидание калибровки тракта (цикл 0x339 итераций).
  6. Запуск тракта на новой частоте. Тактовая сетка (PLL/CAR) при этом не перезапускается.

### Регистры частоты и полосы
- **`0x883b3c`**: настройка частоты канала:
  - CB1 (каналы 1..6, enum 0..5): `{0x6b, 0x68, 0x65, 0x62, 0x62, 0x62}000101`
  - CB2 (бондированные каналы 9..12, enum 6..9, ширина 4,32 ГГц): `{0x69, 0x66, 0x63, 0x60}000101`
- **`0x8851c0`**: регистр индекса бондированного канала (EDMG CB2 Channel Index).
  - *На чипах Sparrow данный адрес возвращает `0xdeadbeaf`.*

### 13-отводный цифровой фильтр модуляции
Конфигурируется функцией `file_hw_drivers_phy_20` @0x2599c:
- На Talyn адреса фильтра: `0x883d74`, `0x883d78`, `0x883d7c`, `0x883d80`.
  - Коэффициенты CB1: `0xd8d8ecfc`, `0x3b573b00`, `0xecd8d800`, `0x883d80[7:0] = 0xfc`, бит 8 = 0.
  - Коэффициенты CB2: `0x11fdf9fd`, `0x4c574c30`, `0xf9fd1130`, `0x883d80[7:0] = 0xfd`, бит 8 = 1 (`cb2_en`).
- **Сравнение со Sparrow**: у Sparrow этот же 13-отводный фильтр расположен по адресам `0x883d64 … 0x883d70` (смещение ровно `-0x10`).
  Коэффициенты CB1 на Sparrow идентичны Talyn (`0x883d70 = 0x1fc`, бит 8 = 1). Бондинг CB2 на Sparrow аппаратно отсутствует.

## 4. Регистровые различия: Классы A, B и C

Сравнение карты RGF Talyn (719 регистров fw, 233 регистра uc) со снимками регистров Sparrow:

1. **Класс A (Shared, 451 регистр)**:
   - Полностью совпадают по адресу и функционалу: USER/CAR, PCIe, DMA, базовый MAC, MAC-SXD, PHY-RX, базовый ABIF.
2. **Класс B (Dormant on Sparrow, 307 регистров)**:
   - Аппаратно присутствуют в кремнии Sparrow, но не используются штатными прошивками 4.1/6.2:
     - `0x887100 … 0x8878ff`: таблица состояний после перехода XTAL $\to$ PLL (в сбросе Sparrow уже предзагружены 49 из 57 значений).
     - `0x88613c`: `mac_enable_multi_network` (поддержка до 4 BSSID аппаратно).
     - `0x88c110 … 0x88c11c`: высокоточные метки времени ToA/ToD (шаг 6,06 нс).
     - `0x886f8c`: `HW_MAC_SCHED_SLOT_STATUS` (статус аппаратного планировщика DTI/SP).
3. **Класс C (Absent on Sparrow, 236 регистров)**:
   - Аппаратно отсутствуют на Sparrow (возвращают `0xdeadbeaf` либо вешают шину):
     - `0x8843xx … 0x8858xx` (77 регистров): блок EDMG/CB2, EVM-метр (`phy_rx_evm_config`), память BRP (`phy_brp_mem_parse_config`), блоки радарного зондирования (`phy_radar_*`).
     - `0x880000 … 0x880eff`: SPI-хост сенсинга, таймер TSF (`tsf_timer_*`, `0x880cxx`).
     - `0x8864xx / 0x8869xx / 0x886axx`: менеджер длины кадров FLM (`mac_configure_flm`).
     - `0x88c500 … 0x88c8xx`: аппаратный захват GPS PPS (`0x88c754/64`), расширенный разборщик MAC (`mac_parser_9`). **Внимание:** чтение `0x88c500+` на чипе Sparrow аппаратно блокирует шину PCIe (хост читает `0xffffffff`, требуется power-cycle!).
     - `0x88d000+` (`ext_user_rgf`), `0x88e000+` (CPR), `0x8b0000+` (`dma_ext_rgf`): eDMA и дескрипторные очереди Talyn. Чтение ядром Sparrow приводит к аппаратному зависанию процессора.

## 5. Диспетчер WMI хоста: команды Talyn 7.5

Диспетчер WMI разобран в диапазоне `0x3ce9e … 0x3dd1e`: дерево бинарного поиска `cmp`/`beq` плюс таблицы косвенных переходов `ldw.x.as` со смещениями в `fw_data` @0x805dfc.
Всего зарегистрировано **116 команд с индивидуальными ветвями**:
- **72 команды** общие со Sparrow 6.2 (управление линком, ассоциация, базовый биконинг, сканирование).
- **44 команды** реализованы исключительно в Talyn:
  - **Радиовидение и радар**: `WMI_SENSING_ENABLE_CMDID` (0x100), `WMI_SENSING_CFG_CMDID` (0x101).
  - **Очереди eDMA**: дескрипторные кольца `0x9c0 … 0x9c5`.
  - **Дальнометрия FTM (ToF)**: расширенные команды `0x991 … 0x999`.
  - **Адаптация скорости Rate Search**: `WMI_RS_CFG_EX_CMDID` (0x857), `WMI_RS_ENABLE_CMDID` (0x858).
  - **Управление EDMG**: `WMI_FORCE_DISABLE_EDMG_CMDID` (0x859).
  - **Управление температурой**: `WMI_THERMAL_THROTTLING_CONFIG` (0x940), `WMI_THERMAL_THROTTLING_STATUS` (0x941).
  - **Метрики линка и AoA**: `WMI_AOA_MEASURE_CMDID` (0x923), `WMI_LINK_STATS_CMDID` (0xa0c).
  - **Замкнутая регулировка мощности TPC**: `WMI_TPC_SET_MAX_AVG_TX_POWER` (0xa20).

## 6. Регистры локального чтения MSXD (r36..r56) в ucode

Микрокод Talyn использует расширенный регистровый файл MAC MSXD:
- `r36..r39`: статусные отчеты PPDU (`PPDU_REPORT_1_R36` … `PPDU_REPORT_MISC_R39`). Позволяют мгновенно определить тип принятого кадра (ACK, QoS Data, Mgmt, Beacon, Reservation), адресное совпадение (`my_frame`, `bssid_match_valid`), RSSI и MCS без программного разбора заголовка в ОЗУ.
- `r40`: мультиплексированный регистр, читаемый по команде MAC `0x1d00X000` (где $X$ — 4-битный селектор):
  - `Селектор 0`: `BACKOFF_IFS_STATUS` (0xa7b760) — состояние NAV, признак занятости среды `idle_detect`, оставшиеся слоты AC1..AC4.
  - `Селектор 3`: `REMAINING_TIME_RD` (0xa7b76c) — остаток текущего периода TXOP / NAV в микросекундах (`txop_initiator_open_txop_flow` проверяет порог $r40 < 0x31$).
  - `Селектор 4`: `BI_COUNTER` (0xa7b770) — счетчик текущего BI (биты 0..25) и флаг синхронизации `bi_sync` (бит 31).
  - `Селектор 5/6`: `TSF_LOW_R40` (0xa7b774) / `TSF_HIGH_R40` (0xa7b778) — аппаратный TSF.
  - `Селектор 7`: `REMAINING_BI` (0xa7b77c) — время до окончания текущего BI в мкс.
  - `Селектор 10`: `PHY_PLCP_RX_SIGNALS_R40` (0xa7b78c) — MCS, флаг пакета EDMG, RSSI feedback, срез вторичной CCA.
  - `Селектор 12`: `BF_METRIC_R40` (0xa7b794) — отношение SNR и метрика диаграммы направленности.
- `r42..r46`: расширенные отчеты EDMG (`PHY_RX_PLCP_EDMG` 0xa7b7f0, `MTP_QUERY_RESPONSE_1/2` 0xa7b7f4/0xa7b81c): ширина полосы `bw_code`, число пространственных потоков `num_of_ss`, длина защитного интервала `gi_cp_length`, агрегация каналов.
- `r47`: `DIRECT_TX_CMD_STATUS` (0xa7b8c4), статусы переключения РЧ-тракта `RFC_SWITCH_ERROR_STATUS` (0xa7b8d0).
- `r54`: аппаратные события MAC:
  - Бит 4: наступление границы слота DTI/SP (квитируется записью `0x49000010`).
  - Бит 17: импульс синхронизации GPS PPS (квитируется записью `0x49020000`).
